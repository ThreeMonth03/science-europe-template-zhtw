# Q1 再利用準備敘述原型：本機驗證

這是範圍有限的原型，不是正式發布、DSW 部署或整份文件完成驗收。
正式中英輸入仍為 **0.3.48**；正式 Jinja、翻譯樹、樣式與工作流程未改。

## 結果與根因

修正 Q1「一致化處理、機器可讀格式、後設資料提供」的九組固定中英句子。
中文以「轉換後的資料」取代「此形式」，保留會提供／不提供／尚未回答的區別，
不改使用者原文、標準名稱、連結或段落數。

前兩次純文字替換演練未通過翻譯閘門。查明既有轉換工具對此段使用
`computer_readable_original` 的整塊逐字比對規則：修改英文敘述後，規則不再
適用，翻譯單位退回碎句。並非只要換回連接詞就能解決。

通過的方案在**英文原型**內讓各分支輸出完整句子，再走原有鎖定的轉換工具；
沒有新增工具特例或手寫一套中文 Jinja。九組舊／新句子都有可核對的清單。
這是減少日後與 upstream 措辭逐字綁定的局部實驗，尚未全面移除其他特殊規則。

## 限制與下一步

這輪未修改 CSS、Word 樣式、其他題目、空白標準名稱處理或 filtered-KM
可達性邏輯。LibreOffice 預覽不是 Microsoft Word 相容性驗收；
也不是 DSW 伺服器端發布驗收。

建議下一步把已通過的**這一小段英文整句結構與九組譯文**整合至正式來源，
維持單一英文→中文流程；再接正式 CI／原生回歸，避免把原型 ID 直接當正式版發布。
其他碎句與語氣問題按題目逐段處理，不做會誤改使用者答案的全域文字清洗。
