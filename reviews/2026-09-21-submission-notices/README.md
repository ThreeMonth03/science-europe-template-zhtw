# 提交版系統提示切換：原生試作

本輪完成「已標記系統提示」的來源端切換試作，**不是全域開關完成或正式發布**。
正式來源鎖、中英文套件版號仍為 0.3.43，兩個 repo 的模板與 748 組翻譯沒有修改。
測試只在本機合成專案執行，沒有存取 production 或 keyring。

## 切換方式與內容保留

在既有套件的 Jinja 原始碼加入提交模式條件，不在產出後用 CSS 或字串搜尋刪內容。
英文 114 處、中文展開後 116 處標記提示（另各有一處未標記的蒐集說明提示），
涵蓋 18 個來源檔。中文多兩處來自原有展開分支。這是來源節點數，不是每份文件的缺漏數。

「需要軟體但未列工具」、「有使用限制但未補條件」、「已選其他品管方法但未補細節」
保留已填的肯定事實，只去掉漏填提醒；未回答的品管決策不會被改成肯定句。
原有部分提交模式繼續生效；沒有指定模式或指定未知值時仍保留內部檢核提示。

結構檢查共 **264 組**，即 65 個既有案例加 1 個新增案例，
乘中英兩語與 autoescape 開／關。所有檢核版字串不變；提交版的全文、標點、
已填內容區塊、明確否定答案、連結與六大節／十五題均核對通過。

新案例刻意把 `data-gap` 樣式寫進使用者回答，並包含「尚待補充」、`N/A`、`0`、
`Original.csv`。這些原文在 HTML、PDF、Word 中都保留。
[中文樣張中的黃色方框](visual/notice-mixed-submission-chinese-p2.png) 是這段刻意加入的
使用者原文，**不是殘留的系統提示**。

## 原生結果

三種案例、中英文、檢核／試作提交共 12 組比較；包含 18 份原生基準與 36 份試作輸出，
共 54 份 HTML／PDF／DOCX，另有 18 份 LibreOffice 預覽。
六組檢核控制的 HTML、整份 Word 正文元件、PDF／Word 座標及逐頁影像完全不變。

| 案例 | 英文：檢核 → 試作提交 PDF／Word 頁數 | 中文：檢核 → 試作提交 PDF／Word 頁數 |
| --- | --- | --- |
| 全空 | 4／3 → 3／2 | 3／3 → 2／2 |
| 肯定分支缺細節＋使用者提示樣式原文 | 7／6 → 6／6 | 6／6 → 6／6 |
| 長篇用途＋缺幣別 | 10／9 → 10／9 | 9／10 → 9／10 |

PDF／Word 完整字元數量與段落內容核對通過，長用途 60 段、原本金額、續頁識別
及尾句均保留，沒有新增頁數。Word 清單的 `o` 符號先依編號設定與頁面座標綁定，
不能把原文的字母 o 一律刪除。表頭增加只接受有來源可核對的長表分組／續頁重複。
字元數量檢查不是通用 PDF 語意或閱讀品質評分；表格的完整視覺順序仍需人工審閱。

## 尚未完成與下一步

- 「未命名／N/A／尚未提供計畫或人員」等未標記佔位內容仍可能出現；不能稱為全域關閉。
- 已選其他品管方法但細節空白時，既有「將進行品管」與新「採其他方法」仍可能連續成兩個
  重複短段落；接回英文來源前應合併，避免再次增加閱讀負擔。
- 新增的三組英中固定敘述目前只在試作配對文字表中，尚未進正式 translation tree。
  下一步應收回英文來源，再經既有翻譯流程同步，不能長期維護兩套 Jinja 補丁。
- 不替未回答內容補造答案，不表示內容已完整、符合國科會或 Science Europe 全部要求。
  完整問卷檢核清單、真實專案、Microsoft Word 與整體排版仍待驗收。

## 配額失敗與清理

首次試作在第一個 HTML 匯出時遇到本機 DSW 配額不足：需要 15.95 MB、剩餘 11.99 MB。
保留 `failed-quota/` 的原始失敗報告；沒有把失敗改寫為成功。
只移除已完成基準的兩個模板、首次失敗的一個模板、以及重跑完成的兩個模板，
共五個本輪專用本機模板。每次都驗證沒有專案／文件引用且 ZIP 備份存在。
沒有調高配額、刪除其他專案或變動資料卷；stock worker 已還原，四個本機服務全部停止。

`package/`、`provenance/prototype.json` 可精確還原全部來源修改；除套件 JSON 中明列的
Jinja 內容以外，其餘 metadata、格式 UUID、字型、CSS、Lua、Word reference 全部不變。
HTML 的內嵌公開字型以可逆雜湊引用封存，原始雜湊另存，不當作 PDF 專屬入口。
