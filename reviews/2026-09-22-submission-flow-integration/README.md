## 仍未通過的整體品質項目

抽看新版 8 頁，**不代表人工看完全部 302 頁**。中文全空提交 PDF 與 Word 預覽
均為 2 頁（含概要頁），15 題可放在同一內容頁；英文全空提交 PDF 仍為 3 頁，
第 15 題獨占尾頁並留下大片空白。這是原型既有問題，本次整合沒有新增，但仍須修正。
不能將「與原型一致」誤認成這個尾頁已通過閱讀品質驗收。

下一輪優先以保留所有題目的局部間距實驗處理英文孤題，再持續檢查中文數量句型、
中英語氣與全篇閱讀銜接。自由文字不因模板看起來更流暢而被刪除或改寫。
仍未做 Microsoft Word 或目標 DSW 伺服器驗收，亦未擴大套件 `allowedPackages`。

等待 CI 時另做了兩輪、共 16 份全空 PDF 診斷，**不計入上述整合驗收，也未接回
來源**。原有標題 `!important` 確實使 `break-after` 保持 `avoid`，但單獨解除仍為
3 頁；第一個整份文件條件選擇器在實際引擎命中零個節，因此其間距實驗無效。
第二輪的無條件章節間距控制可讓英文變為 2 頁，中文仍為 2 頁，15 題全文保留；
人工抽看該英文內容頁，所有題目可讀且沒有孤立尾題。此控制沒有安全套用範圍，
**不能直接採用**。逐節空題選擇器在全空控制命中六節，接下來需補混合、長文與
檢核版的反向控制，再做新的原生比較。相關規則與結果在 `diagnostics/`，不假裝已修好。

## 證據與發布順序

`native/private-parity-summary.json` 是去除專案內容的彙總及雜湊憑據，不是公開可
重播的真實專案。答案、context、PDF、DOCX、截圖與完整私有 log 都留在 repo 外。
公開合成案例仍在英文原型及中英測試中；`checkers/` 封存本輪比較器與套件檢查器。

提交／檢核是同一來源的格式選項，不拆永久分支。未來要推送時，必須先讓英文
鎖定 commit 可從遠端取得，再推送中文配對分支並跑 CI；兩者確認後才合併。
本輪不建立正式 release tag。後續 upstream 升級另走 `upgrade/*`、檢查 KM、
句型／翻譯與版面差異後更新精確鎖定，不把 upstream 的排版直接合進已驗收版本。
