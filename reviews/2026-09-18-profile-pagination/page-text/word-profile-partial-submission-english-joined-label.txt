Section 2: Documentation and data quality

We will be documenting the data with Dublin Core metadata standard. Metadata will be openly available.

Data storage and file conventions
We will use a filesystem with files and folders. We document how we manage file versioning for files and

4. What data quality control measures will be used?
Quality control is planned for Coastal temperature measurements.

Section 3: Storage and backup during research process
5. How will data and metadata be stored and backed up during the research process?
There is a shared workspace used during the project for working with data. Storage needs will be the
same during the whole project. All essential data will also be stored elsewhere to prevent a total loss of
data. We will make automated backups of all data stored outside the workspace.

6. How will data security and protection of sensitive data be taken care of during the research?
Project members will not carry data with them (e.g. on laptops, USB sticks, or other external media). All
project web services are accessible via secure HTTP (https://...). Project members have been instructed
about both generic and specific risks to the project.
