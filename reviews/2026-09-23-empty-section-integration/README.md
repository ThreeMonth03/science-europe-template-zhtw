## 回歸與第一次失敗

英文只安裝自身宣告依賴的乾淨環境已通過 253 項測試與 TDK 驗證；中文完整
461 項測試通過。新版套件中英各 396 組填答／模式／跳脫條件通過，公開固定
worker 的 63 組選擇器與 28 組列印／螢幕版面控制也通過。

先驗證新版完整差異，才提供逐位元組還原的歷史來源供舊版回歸使用。歷史還原
不是新版呈現結果，原型配方、封存檔與舊版標準未重寫。原型引擎報告仍標示
局部控制範圍；新 wrapper 先驗證正式來源，完整文件則另由上述原生比較驗證。

首次英文單元測試有 3 個失敗：兩個歷史 CSS 診斷會在新增規則後附加已退休的
樣式；一個錯誤版號測試恰好把本次合法的 0.3.48 當成錯值。已修正測試銜接：
精確移除已知 CSS 時保留所有前後字元，仍由完整來源／歷史雜湊檢查拒絕未審修改；
錯誤版號改成不在支援範圍的值。修正後重跑完整測試。失敗紀錄與前三次診斷建置
保留，不把它們當成最終驗收套件。實際模板 CSS 自第一次建置起沒有改動。

已在最終乾淨建置上執行流程中的全部 52 個 Python 指令（含中文完整測試及
51 個候選／引擎檢查），退出碼均為 0。指令、退出碼與日誌雜湊見
`build/local-checks.json`；這不是 GitHub Actions 執行結果。先驗證實際套件，
再以四個執行槽跑獨立指令；只改本機排程，不改測試條件或以部分測試替代。

## 發布界線與下一步

本輪未推送 GitHub、建立 release tag 或部署 DSW，亦未使用 keyring 憑證。
中英以完整 commit 配對，檢核／提交仍為同一來源的格式選項，不拆永久分支。
將來推送時先讓英文鎖定 commit 可在遠端取得，再推中文分支；CI 與成品驗收後
才決定合併／發布。`allowedPackages` 不變，不聲稱新增 KM 相容性。

下一輪聚焦第 1 題固定句型：英文資料協調與機器可讀轉換句有既有文法問題；
中文「將此形式提供給他人」等說法較生硬。將分開檢查句型、標點與中英條件
對齊，保留肯定／否定／未知狀態及原始自由文字，不以重新改寫使用者答案修飾成品。
這仍不是整份 DMP 的科學內容、全面語言品質或國科會繳交驗收。

公開 `native/` 僅包含內容去識別後的彙總、人工檢視記錄與證據雜湊；私有問卷、
答案、PDF、DOCX、截圖與完整私有日誌留在 repo 外。公開摘要不是可重播的真實
問卷 fixture。`checkers/` 保存比較程式，`build/` 保存建置與測試憑據。
