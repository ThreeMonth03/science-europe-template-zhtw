# 提交版空題間距原型

依使用者選擇：**保留原題、緊縮空白**。不刪掉或移走 Science Europe 的 15 題、
不在提交版新增漏填提示，也不替使用者編造答案。正式來源與 pipeline 仍為 0.3.46；
本原型疊在前輪 Q1 摘要實驗上，尚未整合、推送或部署。

## 修改範圍

英文共用判斷器只標記確定沒有可呈現內容的題目；零值、圖片、表格、自由文字、
空的使用者段落及未知結構都不當成空題。HTML／PDF 只縮小題目間距，保留空答案
容器。Word 保留原本 Heading3、文字與書籤，只調整空題的段前距離與連頁設定。
檢核版不套用這些排版變更；已填題目及原始回答不改。

中文照常由客製英文經既有工具生成，775 組中英翻譯配對不變。沒有另改中文 Jinja、
字型或 reference.docx，沒有修改 upstream 分支，也沒有新增永久的提交／檢核分支。

## 兩次被攔下的錯誤

1. 第一輪 DOCX 段落屬性被 Jinja 的 Markup 替換機制跳脫成文字。完整原生比較拒絕
   接受；原先 `autoescape=False` 的引擎測試不能代表 worker。修正只信任固定 XML
   常數，保留使用者文字的跳脫；回歸測試涵蓋開啟／關閉自動跳脫與 Markup 輸入，
   實際 Pandoc 測試也改用自動跳脫。錯誤候選的 Word 減頁不計入成果。
2. 修好 Word 後，兩個含「其他使用條件＋表格」的提交 PDF 卻由 3 頁增為 4 頁。
   內容比較通過不代表排版通過，獨立頁數關卡明確失敗。十份 CSS 對照重現原生
   文字座標，定位到空答案容器的 `display: none`。最後移除該規則，只緊縮間距，
   再重建實際套件、重新產檔驗證；不以診斷用 PDF 代替正式流程產物。

失敗候選及紀錄各自封存，不回填成成功。早期口頭回報曾混淆空白中文文件的頁數：
基準 PDF 原本就是 2 頁；3 → 2 頁指 Word 預覽，不是 PDF。
第一個錯誤候選曾出現的 Q8 Word 標籤拆頁，修正跳脫後已未重現；另以 16 個
合成邊界觀察記錄基準／候選、中英、兩模式。這不是宣稱所有 Q8 長文都已驗收。

## 版本與驗證紀錄

短期分支皆為 `fix/empty-question-spacing`；跨 repo 配對依完整英文 commit、
中文配方、工具版本、翻譯與套件 SHA-256，不依賴同名 branch。
原型使用獨立 ID `science-europe-empty-question-prototype[-zhtw]`／測試版號 0.3.47，
不代表正式版本已發布。建置、測試、原生比較與頁數結果記於同目錄的 JSON。

真實專案快照、答案、PDF、Word 與截圖只存本機私有目錄。本目錄只收去除內容的
統計、程式快照及驗證雜湊。Word 預覽使用 LibreOffice，並非 Microsoft Word；
未連線 DSW 伺服器、未取用帳密，也不是新的 GitHub Actions 執行結果。

下一步應將經確認的 Q1 摘要與空題間距回收成英文的一次來源整合，中文再鎖定該
英文 commit 重建，並驗證整合包重現原型。不要讓實驗疊加機制成為長期正式架構。
空白文件仍不適合繳交；閱讀品質、中文語氣與 Microsoft Word 實機驗收仍需持續檢查。
