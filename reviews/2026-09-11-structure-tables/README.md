## 本輪改動與責任歸屬

英文仍從官方 Science Europe 1.30.1 衍生，並保留十五題架構。這輪不是另寫
一套中文條件邏輯，也沒有重新設計整體視覺樣式。

1. **答案與欄位**：修正契約依據、機構資料託管員的識別碼指派分支拼字。
   移除已過時、無法對應 Common KM 2.7.0 的查詢，不猜測替代欄位。
   倫理審查狀態與案號各自保留，不再因缺少另一項或計畫名稱而整段消失；
   同一計畫只列一次。保存費用不再受資料集清單是否存在牽連。
2. **HTML**：修正 Q8/Q9/Q11 的段落與清單巢狀，Q13 不再以清單包住沒有
   li 的段落，並修正未發布分支的多餘結束標籤。這類錯誤可能被 HTML 與
   Word 轉換器以不同方式修復，不只是 PDF 文字抽取的問題。
3. **中文接句**：檔案命名改成自足標籤；軟體名稱與取得位置分開；倫理
   審查進度使用可翻譯的完整句子；保存期間允許中英文依各自語序呈現。
   自由填答內容沒有用 LLM 重寫。
4. **填答疑點**：舊案例的「10」仍不擅補為十年，改顯示缺時間單位提示。
   「費用已預付／儲存庫不收費」顯示核對提示，不武斷判定矛盾。
   新案例改填「10 years／10 年」並選擇已編列儲存庫預算；其他細節仍非完整
   經費或科學計畫範本，不應直接照抄。
5. **表格解析**：原版 worker 與實驗 worker 使用完全相同的英中套件。
   獨立 Docker 映像只在既有 Markdown parser 加上 tables extension。
   原清單／換行前處理保留，不更動 Pandoc、字型或 PDF 樣式。

## 驗證結果

- 英文 27 項、中文流程 15 項單元測試通過。645 個翻譯單位無空白譯文，
  translation audit 與 structure audit 均無違規紀錄。
- 原版 worker：9 案例 × 2 語言 × 3 格式，共 54 份均成功生成。指定內容
  檢查通過，但自由回答的表格仍失敗，留下 28 筆阻擋紀錄（同類根因在不同
  案例、語言及格式重現，不是 28 個獨立根因）。
- 實驗 worker：structured、structured-partial、populated、stress 四案例，
  中英三格式共 24 份均成功生成，原生 HTML／可編輯 DOCX 表格檢查通過。
  中文 PDF 第 3 頁亦已人工確認表格正常。
- 8 個案例／語言配對的套件、問卷、事件與 KM 雜湊相同。全文件的既有
  fact markers 相同，第 2–15 題文字在忽略空白後相同；表格儲存格值均能
  對回原版文字。**没有宣稱第 1 題完整語意等價或全問卷覆蓋率。**
- 既有 88 個答案保留回歸檢查通過；同組案例的段落內 block 問題紀錄
  由上一輪 12 筆降為 0。另對 Q8/Q9/Q11/Q13 檢查清單直屬子節點。
- Common KM 2.7.0 靜態檢查：十五題未定義變數 0、引用不存在實體 0。
  舊案例 460 筆輸入中，116 筆符合字串比對條件且找到文字，344 筆仍待
  語意審閱；沒有把靜態或文字檢查當成完整性證明。
- 長文字案例在兩種 worker 的中英 PDF／DOCX，均保留預期 80 次測試句。
- 額外對實際轉換後的英中 Jinja 檢查四種倫理審查狀態、缺狀態但有案號、
  無計畫名稱、案號 HTML escaping，均通過。這項使用本機 reply adapter，
  **不是這些特殊分支的 DSW worker 端到端測試**。
- 原 worker 的 image ID 已恢復為原本的 `sha256:5e5c5e1e436feb49fc4cbcd62c2e0ab2785db2141b0fe40d2926906bcfeaebfc`；
  本機四項測試服務停回原狀，資料 volumes 保留。線上 DSW 未變更。

機器報告只代表其宣告範圍，`release_acceptance` 仍為 false；不能以實驗組的
`pilot-report.passed` 取代內容、語言、版面與正式環境的完整驗收。

## 實際閱讀觀察

新案例中文 PDF 為 6 頁、Word 的 LibreOffice 預覽為 7 頁；不是 Microsoft
Word 實測。抽查 PDF 第 2–6 頁、Word 表格頁及原 worker Word 第 5–6 頁：

- 溯源表格已由管線文字變成兩欄三列，Word 中亦是可編輯表格，不是圖片。
- 檔案命名標籤不再拼出「本計畫 的」，大小寫保留；軟體名稱與網址標籤分開。
- 新案例保存期間呈現「10 年（費用已預付）」，舊案例仍留核對提示。
- 修正結構後仍有不同頁面切分：原版 worker 的舊案例 Q5 提示框落在次頁；
  表格實驗的新案例 Q5 正文與提示同頁，但 Q9 在第 4/5 頁間分段。
  不能把單一案例的較佳分頁當成穩定排版規則。
- Q10 仍有三層清單；資料集名稱在多題重複；Word 段距較鬆，仍會把授權
  細節接到下一頁。下一輪應整理這些呈現方式，而非再縮字或刪掉使用者內容。
- 「我們／本計畫／專案」仍未完全統一，部分沿用句子偏問卷口吻。中文接句
  與可讀性有改善，但不是全文中文編修完成。

  永久分支。兩個 repo 的同名 branch 只是工作標籤，真正對應靠
  `pipeline.yml` 的英文 commit 鎖定與產物 manifest。

這次 HTML 小改動也造成翻譯樹大量路徑搬移。因此 upstream 升級要分開看：
英文語意／UUID 差異、翻譯句子差異、實際 PDF／Word 差異，而非只算 Git 衝突。
上游有修正就審閱是否移植；不要直接覆蓋自有的句子結構與 Word 樣式。

worker 修正是另一個版本軸：`experiments/markdown-tables/` 鎖定原映像 digest
與來源 SHA-256，來源不同就拒絕套用。實驗輸出 manifest 明示
`runtime-experiment`，一般 candidate staging 會拒絕，不可冒充模板升版即可
在原版服務修好表格。正式採用前，需決定由 upstream 納入或自行維護 worker。
