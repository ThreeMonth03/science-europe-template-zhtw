抽看六頁後，確認中文 `MISSING` 提交 Word 預覽仍有第 15 題獨占第 3 頁的問題。
原型與正式套件都如此；它不影響本輪「整合是否忠實重現原型」的判定，
但不能因此宣稱整份文件適合繳交。下一輪優先處理這個可重現的排版案例。

讀取實際 DOCX 顯示：空題的 Heading3 已有局部縮距與取消 keep-next；
節標題 Heading2 仍套一般段前 12pt／段後 6pt。PDF 的全空節 CSS 縮距
沒有對應的 Word 節標題處理。這是下一輪要測的原因假設，尚未以修補 A/B 證實。
實驗須保留全部題目、不縮小全域字級、不中斷有答案的章節，也不得改變檢核版。

下一輪最小試驗：先在英文共用 Word 處理層，僅辨識「全部直接子題皆為
可信空題」的節標題，嘗試局部縮距，再走既有中文產生流程。先做原型、不立即升版。

或出現新跑版。PDF 與檢核版不在這個修補範圍，須另外證明不變。
