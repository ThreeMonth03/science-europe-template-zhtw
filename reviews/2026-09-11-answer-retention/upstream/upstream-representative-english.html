    Section 3: Storage and backup during research process

    5. How will data and metadata be stored and backed up during the research?

    There is a shared workspace used during the project for working with data.

    Storage needs will be the same during the whole project.

    All essential data is also stored elsewhere to prevent a total loss of data. We will make (automated) backups of all data stored outside of the working area.

    6. How will data security and protection of sensitive data be taken care of during the research?

    Project members will not carry data with them (e.g. on laptops, USB sticks, or other external media). All project web services are accessible via secure HTTP (https://...). Project members have been instructed about both generic and specific risks to the project.

    During the project we will use shared working space to work with our data but we will store all essential data elsewhere. We make (automated) backups of all data stored outside of the working area.
