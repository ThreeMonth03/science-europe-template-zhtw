# 0.3.20：中英文漏填、續頁資訊與 Q7 轉換修正

本輪完成三個既有缺陷的修正，並修正原生檢查新抓到的 Q7 中文段落邊界問題。
仍為實驗候選，不是完整 DMP／Microsoft Word／線上部署驗收。

## 修正內容

1. **Q7 部分填答**：選擇蒐集個資及 Explore 後，即使已填法律依據，漏答
   保護措施仍顯示待補提示。沒有啟用該追問時不亂標缺答，不代填任何措施。
2. **長篇預算漏金額、幣別或來源**：原生 PDF 維持全寬用途，續頁重複同一筆
   資源名稱、已填資訊及缺答提示。只接受有限的模板自有標記，不放行任意 HTML。
3. **全空白中文 Q15**：題目與四條固定待補資訊同頁，不再讓最後一條獨占一頁。
   這不是把任意長回答整塊綁住，長文與自填內容不套用此規則。
4. **Q7 中英轉換的段落邊界**：英文原本在條件分支內關閉段落，中文轉換後
   遺失結束標籤；新提示因此嵌入前段。現在英文來源共用一個段落結束位置，
   中文重新生成，不依賴 PDF 引擎自動修復 HTML。

原有 722 組英中原文／譯文句對全部保留，新增一條提示，共 723 個翻譯單位。
段落邊界調整造成六個單位需要重新對應；逐項沿用原譯，沒有重新翻譯或改作者回答。

頁面影像是重要頁抽樣檢視，不宣稱人工逐頁看完所有文件。

## 維護與驗收界線

兩 repo 都在 `fix/missing-info-reading`，承接 0.3.19；沒有合併 main、建立正式
tag 或部署線上。英文維護共用邏輯／CSS，中文由既有翻譯樹生成並在
`pipeline.yml` 鎖定完整英文 commit；官方基底仍是 Science Europe 1.30.1。
未引入 JSON／LLM 繞路，未改 Word Lua 或 reference.docx。

測試含英文 137 項、中文 117 項單元測試，英中各 32 個 PDF 片段案例、
長篇分頁引擎測試、8 個缺答群組引擎案例及 12 個 Q7 中英分支檢查。
乾淨重建的英中 ZIP hash 與最後原生測試相同；manifest 與檢查碼一併保存。

本機使用 DSW 4.30、KM 2.7.0、WeasyPrint 68.1，以及先前審閱過的 Markdown
表格修補 worker。這輪沒有重新驗收原版 worker；其 Markdown 表格問題仍是
正式發布的阻礙。沒有存取線上私有專案、keyring 或密碼。

待辦仍包括：短預算欄的提示密度與折行、整份文件的尾頁留白、Q7 更細的法律
依據／保護措施追問及其他未稽核分支、真實研究計畫與 Microsoft Word 開檔驗收。
保留十五題不等於所有問卷回答都已映射，也不等於研究計畫已符合所有法規或
Science Europe 的實質要求。

測試中曾因本機暫存模板累積而遇到儲存額度不足。只清理本輪、無專案引用且
已有 ZIP 備份的暫存模板；既有專案、樣張、資料卷和舊輪次證據未刪除。
