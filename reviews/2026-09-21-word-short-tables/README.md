## 共用修改與邊界

兩語使用完全相同的 Lua 與 XML helper，僅接到兩個 Word 格式的轉換步驟。
HTML／PDF／LaTeX／ODT、舊 Lua、CSS、既有資產與格式 UUID 都不變。

Lua 只選 Q9 直接回答區內的簡單短表：2–4 列、2–4 欄、每格一段簡單文字，
每格至多 80、合計至多 500 加權字元。合併儲存格、巢狀表格、多段落、複雜
內嵌內容、長連續字串、自訂屬性、相鄰表格等均不套用。只有非末列段落使用
既有連頁樣式；末列不拉住後續文章。

後續 `enrich-docx` 消耗 Lua 產生的精確 XML 註解標記，驗證序列化形狀，對
每列直接加入 `w:cantSplit`，最後移除標記。使用者原文不作為選取條件；原文中
像標記的 HTML 註解或跳脫字串不會被當成機器標記。無標記 XML 完全不變。

37 組引擎控制共修改 14 張合格表；相鄰、長表與複雜表不變。15 頁的前後
壓力測試保留全文，長表仍可跨頁，重複表頭核對綁定來源列與實際座標。
離線引擎測試只略過 app constructor；12 組原生 DSW API 測試另驗完整流程。

XML contract 明確綁定所測 Pandoc 3.8.3 與 DSW 4.30 worker。未知標記形狀
會中止轉換，不做猜測替換。日後升級引擎必須重跑無標記控制、37 組引擎、
中英雙模式原生與長表檢查；不能放寬檢查來掩蓋格式漂移。

## 翻譯整合：仍未通過

原生成功的套件將 XML helper 存為未經翻譯展開的 `.xml.j2`。另以既有工具
做最小展開／匯出測試，發現 **7 個機器 XML 片段被誤判為譯句，展開也改變
了 helper**。因此目前明列 `source_integration_allowed=false`。

相同 helper 改存 `src/word/short-tables.xml` 共用資產，最小展開／翻譯同步
測試通過：零譯句，Lua 和 XML 逐字節保留。但這個資產路徑**尚未驗證 DSW
原生套件載入與渲染**。兩項分開成功，不等於完整建置已接通。

`translation/jinja/` 保存失敗演練；`translation/asset/` 保存替代演練。
兩者都只有共用 helper 與 metadata，不是假裝跑過完整英文／中文來源。
下一步先驗 `.xml` 資產路徑，再把本輪與前幾輪原型接回英文共用來源，循原有
翻譯流程生成中文；配對版號、中文鎖完整英文 SHA，不另維護第二套中文 Word
邏輯，也不為檢核／提交新增永久分支。

## 失敗、重測與保存

初始相鄰表格規則會改變 Pandoc 自動插入的空段落，被嚴格 XML 還原核對抓到，
故限定不處理相鄰表格。第一輪原生結果通過後，負向測試又發現額外的自閉合
`<w:p/>` 未被 guard 擋下；已補上檢查並重跑 37 組引擎及全部 12 組原生測試。
`initial-guard/` 保留第一輪套件 JSON、報告與清理收據，不能作最終候選使用。
最終 helper 與初輪只差明列的四行 guard，其他套件內容完全相同。

最終成品不加工；HTML 僅為封存檢查而抽離字型，另附原始 SHA／字型收據。
先前基準由完整 seal 綁定，不重複拷貝；重現程式存於 `reproduce/`。
兩輪共產生 72 份原生成品，各自限縮刪除兩個本機暫存模板，ZIP 備份仍留
本機 outputs；容量設定已還原、stock worker 已還原、四個專屬 pilot 服務停止。
未讀取正式 keyring、未接觸正式 project，英文／中文來源與 0.3.44 版號不變。
