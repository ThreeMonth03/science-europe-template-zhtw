We will be documenting the data with Dublin Core metadata standard.

Metadata will be openly available including instructions how to get access to the data. Metadata will be

Data storage and file conventions
We estimate the storage space that the project will require for all data and software (including temporary
storage) to be 2048 gigabytes. We will use a filesystem with files and folders. We document how we
manage file versioning for files and folders.
File naming conventions:

Quality control measures for Coastal temperature measurements: measurement calibration, data entry

Section 3: Storage and backup during research process
5. How will data and metadata be stored and backed up during the research process?
There is a shared workspace used during the project for working with data. Dedicated specialists will
operate the shared workspace. Storage needs will be the same during the whole project. All essential
data will also be stored elsewhere to prevent a total loss of data. We will make automated backups of all
data stored outside the workspace.

Archival during the project
Data will be archived in cold storage during the project. The archive will be stored on tape. The archive
will be stored at a remote location.
Changes to archived data will require re-archival. Frequent backups are required because the archived
data changes frequently. These backups will be used to recover from accidental changes or deletions.
