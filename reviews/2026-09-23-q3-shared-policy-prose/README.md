## 初版未通過，因此縮小適用範圍

初版合併第 3 題的固定政策段落：中文句號接漢字不補空格，其他邊界保留空格。
雖然保留英文文字，原生 PDF 檢查仍發現英文控制案例的座標差 **0.013055 pt**，
且 72 dpi 像素改變。因此不能把初版當成驗收通過，也不擴大容差來通過測試。
早期失敗、初版程式與產物保留在本機私人證據目錄，和新一輪結果分開。

縮小後只有整段恰為 2–3 個純文字固定段落，且每個邊界都是中文句號接 BMP
漢字時才合併。任何英文／混合邊界、原文區塊、缺漏提示、複雜標記、實體字元、
未知屬性、重複字典事實或不完整句子，都讓**整段逐位元原樣回退**。
字典事實屬性移到 span，文字、狀態、順序、原有內部空格不變。

PDF 和 Word 共用 Jinja 決定，不增加各自的語言判斷。只有 Q3 capture 和一個
helper 可變；CSS、Lua、Word 樣式、字型、轉檔步驟、775 份翻譯檔不變。
未接句案例要求 HTML bytes、DOCX 組件（時間戳除外）、PDF 座標和像素不變。
