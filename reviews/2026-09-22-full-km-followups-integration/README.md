## 證據與限制

`native/private-parity-summary.json` **只是私有驗證的彙總與雜湊憑據**，不是公開可
重播的專案樣本。回答、PDF、Word、截圖、context 與完整私有 log 都留在 repo 外。
公開可重播的合成範例仍在前輪原型檔案與目前單元／分支測試中。

本輪比較器首次因頁面查找層級錯誤留下零頁 raster 計數，該結果已拒收並保留在
私有紀錄。補上非空頁目錄及四項正反向控制後，全部 32 組重新完整比對通過。
彙總只採用修正後的結果。原始稽核 486 個檔案、前輪原型 560 個檔案均核對未變。

此輪未使用憑證、未改寫線上專案、未部署，也未推送新版至 GitHub。Word 預覽由
LibreOffice 產生，不是 Microsoft Word 驗收。英文套件未擴大 `allowedPackages`
到 `root-zh-hant`；離線跨語案例不代表伺服器相容範圍已擴大。

仍待下一輪處理：整篇短段落節奏、空題標題、中英文語氣一致性，以及完整
Science Europe／KM 覆蓋與提交前完整性檢核。局部修補成功不等於正式可繳交。
