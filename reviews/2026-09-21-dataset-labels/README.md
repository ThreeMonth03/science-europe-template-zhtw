# 提交預覽：缺名稱資料集保留中性編號

依使用者確認，名稱未填但資料項目存在時，提交預覽保留中性編號，不刪整筆資料。
這是接續已標記提示與概要／品管調整的第三層**試作**；尚未整合英文来源、
748 組翻譯或正式版號，沒有部署到正式站。來源仍鎖定 0.3.43。

## 名稱與編號規則

| 問卷清單 | 中文標籤範例 | English |
| --- | --- | --- |
| 儀器資料 | 儀器資料集 1 | Instrument dataset 1 |
| 參考資料 | 參考資料集 2 | Reference dataset 2 |
| 非參考資料 | 非參考資料集 1 | Non-reference dataset 1 |
| 非儀器資料 | 非儀器資料集 1 | Non-equipment dataset 1 |
| 產出資料 | 產出資料集 2 | Produced dataset 2 |

十四處名稱 fallback 共用一個標籤 helper，依**原始問卷清單的位置**編號。
同一清單的同一項目在各題顯示相同編號；不同清單不假定是同一筆資料。
第 8 題只選出原清單第 2 筆時，仍叫「參考資料集 2」，不使用篩選迴圈的 `loop.index`。
這是文件中的位置標籤，不是永久識別碼；如果問卷項目重新排序，編號會隨原始清單改變。
已填名稱原樣保留，包括真的填了 `N/A`、「（名稱尚未提供）」或「儀器資料集 1」。
預設／內部檢核／未知模式維持既有提醒；不新增永久 review／submission 分支。

## 邊界與下一步

本輪只處理資料集名稱，不包括姓名、專案／資源／軟體名稱、未命名格式及 ORCID 解析問題。
不補造答案、不宣告 Science Europe／國科會合規，也不是 Microsoft Word 或全部 PDF 版面驗收。
下一步把已驗證的三層規則收回英文共用來源，再循既有翻譯樹產生中文與配對版號；
不要長期保留英文、中文各自的 Jinja 試作補丁。其餘佔位文字仍需明列規則和測試。

使用本機 DSW 與公開合成回答，沒有存取 production 或 keyring。
第一組基準只涵蓋三類清單，完成後另建涵蓋五類的新基準；未覆寫舊輸出，
`superseded-*` 保留其執行／清理紀錄，但它不計入本輪四組比較。
編號試作共清理六個本機專用模板（舊基準 2、新基準 2、試作 2），
均確認無專案／文件引用且有 ZIP 備份；原廠 worker 已還原，四個本機服務已停止。
