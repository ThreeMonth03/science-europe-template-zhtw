## 本輪改動

- 提交模式省略未填的計畫編號、開始／結束日期，以及整張沒有資料的概要表。
  沒有任何計畫時省略空的概要節；没有人員清單且沒有實際創作者時省略空的人員節。
- 補助編號未填時，不顯示提醒或多餘冒號；已填機構、編號與核准／未核准狀態保留。
  這個分支有結構與專門單元測試，本輪原生案例沒有經費來源，不宣稱其原生分頁已驗收。
- 未列儀器時省略 Q1 的系統提示，不把它改成「不使用儀器」。
- 已選其他品管方法但未補細節時，將固定方法與「其他方法」合成一段。
  只有其他方法時也只保留一個肯定敘述；自由回答的段落、未知選項和明確否定不改寫。

範例：「沿岸水溫觀測資料的品質管控措施包括校正量測結果、資料輸入檢核及其他品質管控方法。」
固定方法與其他方法的狀態仍分開標記，不把缺少其他細節標成完整。
