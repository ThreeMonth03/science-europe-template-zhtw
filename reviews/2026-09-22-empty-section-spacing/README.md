# 全空節的列印間距原型

本輪處理 0.3.47 英文全空提交 PDF 的第 15 題獨占尾頁。原型已通過本機原生
比較：英文全空由 3 → 2 頁、英文長文控制由 7 → 6 頁；其他 26 組 PDF 不增減頁。
15 題、已填答案、使用者原始清單／表格全部保留。不是刪題或縮小字體換取頁數。

**正式來源仍是 0.3.47；這是尚未接回來源的實驗，不是發布或整體繳交驗收。**

## 驗證範圍

- 英文 250 項單元測試與 TDK 驗證，中文 458 項單元測試通過。
  英文使用只安裝自身宣告依賴的乾淨環境。
- 中英各 396 組既有問卷／模式／跳脫條件的 Jinja 輸出逐位元組不變。
- 公開固定 worker 的 63 組選擇器測試、28 組列印／螢幕版面對照通過。
  這是局部引擎控制，不冒充完整文件驗收。英文 CI 已新增該引擎步驟。
- 比較器 14 項正反向測試通過，包含遺失內容、額外 DOCX 組件、頁外文字、
  缺少／重複標題、節標題與首題拆頁、第 8 題資料集名稱與說明拆頁。

原生比較使用兩份真實專案離線快照及五種合成控制，涵蓋中英／檢核／提交共
28 組，直接執行新套件宣告的 HTML／PDF／DOCX 步驟，再產生 28 份 LibreOffice
預覽。不是修改成品副本。PDF 共 151 → 149 頁，Word 預覽維持 151 頁：

- 三種 HTML 入口只差精確的共用 CSS 後綴，題目與正文完全不變。
- 所有 DOCX 組件一致，只允許核心建立／修改時間戳不同。
- PDF 只移除每頁已確認的產生器頁碼後比對全文；Word 包含全部原始文字和頁碼
  直接比對。全部內容與字型保留，沒有空頁或頁外文字。
- 所有檢核 PDF 及沒有合格空節的提交 PDF，共 115 頁的文字座標及 72 dpi
  頁面影像不變；151 頁 Word 預覽也逐頁相同。
- 所有 15 題標題保持完整、沒有新增節標題與首題拆頁。完整／其他條件控制的
  第 8 題資料集標籤與說明也沒有新增拆頁。所有案例均未增頁。
- 前輪封存的 1,052 個私有檔案核對未變。

首次比較器錯把 Word 無頁碼的封面當成必須有頁碼而中止。已保留原始程式與
失敗 log 雜湊，修正為 Word 完全不剝除任何文字，補測後重跑全組成功；
沒有為了通過檢查而修改模板或放寬正文一致要求。

這些是本機結果，不是 GitHub Actions 的執行結果。前輪 49 項流程檢查沒有在
本輪全部重跑；本輪新增原型的引擎、建置及原生比較另有獨立紀錄。

實驗。將來 upstream 升級走 `upgrade/*` 並重新驗證來源、KM、翻譯及實際成品，
不把 upstream 排版直接合入已驗收版本。

`build/` 保存兩次建置與本機測試憑據，`native/` 只有去除內容的摘要、檢視記錄

及完整私有 log 留在 repo 外；公開摘要不是可重播的真實問卷測試資料。
