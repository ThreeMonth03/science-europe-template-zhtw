# 0.3.22：第 8 題 Word 名稱與授權說明連頁

短期分支 `fix/q8-word-labels` 承接 0.3.21。英文來源以 `pipeline.yml` 鎖定；
官方基底與轉換工具未變，不建立永久中文排版分支。

上一輪中文 `personal-transfer-complete` Word 的 Q8 資料集名稱在第 4 頁末，
授權說明在第 5 頁。Word 清單規則原本只連接前一項結尾與下一項，沒有連接
同一項的名稱與說明。本輪只在 Q8 直接清單中的短名稱使用既有 `Pilot List Lead`
樣式，不改文字、段落、標點、條列編號或連結。

保守範圍：純文字名稱最多 80 顯示單位、說明最多 320，中文計兩單位，清單
最多 32 項。每筆各自判斷；長回答、附加屬性、圖片、巢狀清單／表格不套用。
不將整份 Q8 或長自由回答強制保持同頁。

英文只改 Word Lua；731 個翻譯檔案完全相同，Jinja、PDF CSS、Word reference
樣式和字型也不變。CI 以先前保存的 0.3.21 source hashes 檢查，不能只靠文字
宣稱修改範圍。另加 26 組固定 Pandoc AST 探針及 Word XML 修改範圍測試。

原生案例包括原本的跨頁反例、空白、否定、完整控制組，以及新增的 30 段自訂
限制與 8 筆資料集；兩種語言都先檢查編譯後的 KM 路徑，再產出 HTML／PDF／
DOCX。新長／多筆案例另外用上一版套件產生對照，不把新版充作舊版。

本輪仍不代表 Microsoft Word 或整份 DMP 驗收。短預算提示折行、整體留白、
長篇複雜 Q8 閱讀與 stock worker 的 Markdown 表格仍是後續工作；不發布正式版。
