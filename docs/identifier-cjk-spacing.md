# 0.3.28：中文固定句的接點

第 13 題的中文固定句不再額外插入西文空格；英文句間、管道名稱與儲存庫
種類之間的分隔、所有使用者原文保留。原因在 PDF CSS 與 Word Lua 的兩套
銜接實作，不在這些句子的譯文。只改英文共用來源兩處，731 個翻譯檔與
全部 Jinja、字型、Word reference、字級與行距不變。

八組中英 48 個原生輸出及 16 份 LibreOffice 預覽通過選定檢查；PDF／DOCX
各只少 10 個指定空格，頁數前後相同。11 組未受影響對照的 PDF／Word
預覽文字座標也相同。詳見 [前後樣張與限制](../reviews/2026-09-16-identifier-spacing/README.md)。

其他政策段落另含模板字面換行空白，不能套用一次全域去空白。
下一步應先挑完整案例的 Q1／Q5／Q11，決定哪些固定句真的該連讀，再測
中英文、缺答與自由回答邊界；不是把所有段落壓成一段，也不刪使用者原文。
