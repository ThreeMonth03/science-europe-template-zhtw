# 2026-09-14 CI 修正

英文 `feat/reading-units` 的 [34798398646](https://github.com/ThreeMonth03/science-europe-template/actions/runs/34798398646)
在測試收集時失敗：`ModuleNotFoundError: No module named 'bs4'`。
先前 `feat/quality-reading` 也有同一問題。新測試用了 BeautifulSoup，
但英文 requirements 沒有宣告；本機共用工具環境已有該依賴，因此掩蓋了錯誤。

修正：英文加入 `beautifulsoup4==4.15.0`，在全新、無 system-site-packages 的
venv 僅安裝英文 requirements，54 項測試及 TDK verify 通過。
英文修正 commit `6d657ed52681fc8ef0f0a2dd01d778c8cce7519f`，
[CI 34798714246 通過](https://github.com/ThreeMonth03/science-europe-template/actions/runs/34798714246)。

中文加入獨立英文 venv 的 CI gate，先執行鎖定英文的完整 `make check`，
不能再由中文／工具安裝的依賴掩蓋英文缺漏。
修正 commit `81d3647b6f9aa41807df02eefae3836f908d6359`，
[CI 34798737063 通過](https://github.com/ThreeMonth03/science-europe-template-zhtw/actions/runs/34798737063)。
以上修正已由下一輪 `feat/format-volume-reading` 承接；舊失敗 run 不會被改寫。

新一輪另外在中文 CI 執行 76 組格式／容量雙語分支 probe。
這仍是建置與離線測試，不能當成完整 PDF／Word 驗收。

獨立待處理項目：工具 repo `master` 的每日排程
