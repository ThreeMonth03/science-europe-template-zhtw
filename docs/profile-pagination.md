# 0.3.38 後的分頁修正實驗

本輪沒有發布 0.3.39，也沒有更改翻譯或正式樣式。
[完整樣張與證據](../reviews/2026-09-18-profile-pagination/README.md) 記錄兩項可行方向：

1. Word：Q11 的短資料集名稱與第一段短摘要合成一個段落，以換行區隔。
   中文提交預覽的題目與正文由 p4／p5 變成同在 p5；其餘三個中英模式控制組仍同頁。
   這需要接受資料集名稱不再是 Heading5，但 Q11 題目仍是 Heading3。
   只重設 keep-with-next 或複製標題樣式的五種試驗皆無效。
2. PDF：將短 Q15 概述與兩列小預算表視為一個閱讀區塊，中文提交版由 p5／p6
   改為同在 p6。四組頁數皆不變、Q15 前的逐字座標不變。
   這只是已知短樣張的實驗；未加入長度／結構上限前不能成為通用 CSS。

PDF 中文檢核控制組仍有前輪原生成品的字型／座標重建差異，獨立程序仍重現差異。
因此只能說四組 A/B 跑完、三份 native baseline 精確重現，不能說四份全通過。
Word 僅用 LibreOffice 25.2.3.2 預覽，未代表 Microsoft Word 已驗收。

  名稱含連結／複雜格式、摘要過長時保留舊結構；另測多資料集，不只處理第一筆。
