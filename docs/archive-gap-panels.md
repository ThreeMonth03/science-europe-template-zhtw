# 0.3.30：Q11 相鄰缺答框

只處理列印／PDF 的三種相鄰配對：

- 冷儲存費用負擔單位＋最低保存期限。
- 延長保存期限的決策者＋決策依據。
- 過時格式處理＋儲存媒體移轉。

兩段共用外框，各自的原文、fact ID、missing 狀態及段落仍保留。內部邊框、
留白調整，字級、行高不變。每組最多兩項，不把整個保存區塊強制綁在同頁。
已填回答、作者段落、「其他保存期限」標籤、需核對或否定狀態都會中斷分組。

Word 本來就沒有這些獨立提示框，本輪保持其正文及樣式不變；HTML 螢幕版
也不改。唯一模板來源差異是英文 `src/layout.css`，732 個翻譯檔、所有
Jinja、Lua、字型與 Word reference 均與 0.3.29 相同。
