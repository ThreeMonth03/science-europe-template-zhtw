# 0.3.30：Q11 相鄰缺答框

只處理列印／PDF 的三種相鄰配對：

- 冷儲存費用負擔單位＋最低保存期限。
- 延長保存期限的決策者＋決策依據。
- 過時格式處理＋儲存媒體移轉。

兩段共用外框，各自的原文、fact ID、missing 狀態及段落仍保留。內部邊框、
留白調整，字級、行高不變。每組最多兩項，不把整個保存區塊強制綁在同頁。
已填回答、作者段落、「其他保存期限」標籤、需核對或否定狀態都會中斷分組。

Word 本來就沒有這些獨立提示框，本輪保持其正文及樣式不變；HTML 螢幕版
也不改。唯一模板來源差異是英文 `src/layout.css`，732 個翻譯檔、所有
Jinja、Lua、字型與 Word reference 均與 0.3.29 相同。

分支 `fix/archive-gap-panels`；中文鎖英文完整 commit 與 0.3.30 套件版號，
不另外維護中文邏輯。舊版 Q11 548 組分支驗證仍執行，新增中英共 128 組
缺答組合與固定引擎的列印／螢幕／頁尾對照。原生樣張與整份文件驗收分開，
不因本輪測試通過就宣稱回答充分或 Science Europe／Microsoft Word 已驗收。

明確否定及 60 段長預算控制。五個分開的缺答框變成三組，提示文字全保留；
