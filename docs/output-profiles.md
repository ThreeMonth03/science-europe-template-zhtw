# 0.3.38 內部檢核／提交預覽（局部實驗）

同一份問卷、同一套英文 Jinja、既有中文轉換流程，提供不同輸出選項。
不另維護兩份題目邏輯、不增加 repo、不以 CSS 隱藏，也不依字串刪除使用者答案。

| 輸出選項 | 用途 |
| --- | --- |
| HTML／PDF／Word－內部檢核版 | 保留原有提示，供作者確認缺答及模板對應限制 |
| HTML／PDF／Word－提交預覽（局部實驗） | 先略去本輪列明的提示；尚不能當作正式提交版 |

原有格式 UUID 不變。新的提交格式 UUID 由英文來源統一管理，中文只翻譯選項名稱。
兩種模式共用版號 0.3.38、字型、CSS、Word reference 與 Lua；LaTeX／ODT 本輪不新增提交模式。
沒有設定模式或遇到未知值，保守保留檢核提示。

## 本輪範圍

Q3 的資料字典、後設資料公開追問、未公開原因、儲存容量與全題缺答提示；
Q5 的儲存地點／備份排程「模板對應限制」；Q11 的保存選擇待檢視提示；
以及整列未填的計畫經費來源。品質管控已選「是」但方法空白時，提交預覽保留
「本計畫將對……進行品質管控」，不把缺少方法誤寫為已完整規劃。
去掉 Q3 提示後若只剩空小標題，也不輸出該小標題；六大節、十五題仍保留。

其他題目與未標記佔位字仍可能出現在提交預覽。完整未填、部分未填、未知選項的
實驗並不等於全面可繳交驗收；也不會自動補答案、宣告合規或自動阻擋輸出。
使用者自行填寫的「尚待補充」、否定答案、限制條件、0、金額、網址、檔名均須保留。
另存的內部檢核清單依檢核版標記產生，涵蓋範圍受模板對應能力限制，不能當作全問卷完整率。

## 版本與升級

本輪在兩個 repo 的短期 `feat/output-profiles-experiment` 分支工作。
不設永久 `review`／`submission` 分支；它們是同版模板的輸出設定，不是不同維護線。
中文 `pipeline.yml` 鎖定英文的完整 commit、工具 commit 與對應版號。
未來 upstream 升級仍在獨立 upgrade 分支做來源差異、語意及中英成品比較後才整合。
若日後必須在 DSW 顯示成兩個 DT，再由同源打包成不同 template ID；本輪尚未做這件事。

## 驗證邊界

舊 0.3.36→0.3.37 證據不改寫。新版來源門檻核對 0.3.37→0.3.38 的五個邏輯檔與
三個薄入口；其餘 prepared source 必須逐檔雜湊相同。既有 Q2/Q3/Q5/Q11 與引擎門檻保留。
翻譯鏈完整保留原 747 組原文／譯文，僅新增一組品質管控肯定句。
Q3 結構移動引起翻譯單元重新編號，一個重複句需人工確認沿用原譯；不是整段重譯。
實際 PDF／Word 樣張與獨立檢核清單另外保存；LibreOffice 預覽不等於 Microsoft Word 驗收。
