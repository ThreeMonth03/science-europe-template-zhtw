# 0.3.51 成品品質盤點：排版、資訊保留、中英文敘事

日期：2026-09-23。這輪是成品診斷，沒有修改模板、翻譯、lock、Word 資產或版號，
沒有重新建置、部署、推送，沒有讀取憑證或呼叫線上 DSW。

## 結論

使用者的三項要求就是驗收標準：中英文 PDF／Word 不傷眼、不漏掉實質填答資訊、
沒有模板造成的語病。依本輪實際觀察，**目前還不能通過**。

不是每題都需要重寫，也不是只有 Word 行距尚待修正。已確認的阻礙集中在：

1. **內容映射不完整**：有回答、但對應文件內容仍未產生。
2. **敘事單位過碎**：同類固定敘述逐筆重複，句子與標點由不同片段拼接。
3. **版面規則誤判或不足**：句中粗體被當成標題；短題組與短回答缺乏合適的跨頁處理。

這三組是修復工作的分類，不代表只剩三個 bug，也不是完整 KM 覆蓋證明。

## 資訊保留檢查：已裁定與尚未裁定要分開

兩份快照共 664 筆儲存的回答，不可直接把 664 當作應輸出的資訊數：

- 一份快照有 615 個問題定義；另一份只有 281 個，並有 27 個可追到的追問題號
  不在其編譯後問題集合中。後者 140 筆儲存回答未被本輪解析為啟用分支；
  可能是隱藏／篩選／不再啟用的分支，不得全部當成模板漏答。
- 依現有快照樹確認啟用的非空自由文字有 76 筆。初步字串比對找到 6 筆疑點。
  其中 4 筆是 C2、1 筆是 C3；另一筆是 Markdown 的 `\_` 轉為 `_`，
  已在 HTML、PDF、DOCX XML 及 Word 預覽重新找到，**不是漏字**。
- 「字串存在」不等於語意正確，也沒有證明所有單選、多選、整合欄位都完整映射。
  C1 正是在自由文字比對之外，回查單選回答與輸出後確認的缺口。
- 尚未把所有已啟用選項逐項完成語意裁定。本報告不宣稱資訊完整率，
  也不把未使用的 UUID 數當作獨立 bug 數。

另有成品中的矛盾敘述可回查到原始選項本身即有衝突，不能替使用者偷偷選一邊。
使用者原文錯字、不同欄位貼入相同文字，以及英文模板中保留中文自由回答，
也不能一律算成模板翻譯失敗。這些與 C1／C2 已確認的模板缺漏分開處理。

## 修復順序與完成方式

### A. 先補內容映射，不改版面壓縮掩蓋缺漏

先以 C1／C2 及相關已填選項完成「回答 → 事實 → DMP 題目」對照，補齊共用英文來源，
再沿既有翻譯流程同步中文。導覽／教學選項與實質 DMP 事實分開裁定。
名稱漏填使用中性編號；缺漏、不適用與明確否定分開；提交版仍不新增漏填提示。
完成判準是每一筆納入修復的事實在中英文 PDF／Word 都可追到，不是只看有沒有文字。

### B. 整理敘事單位，同時審閱兩種語言

處理 N1–N3：固定句型的標點、同一資料集內的相關短句、同一人的多項職責，
以共用語意單位處理。原文、不同資料集例外、連結與表格不能被拼接規則誤改。
完成判準是重讀十五題與整份文件後，沒有新半句、直譯歧義或不必要的重複碎段。

### C. 用內容穩定的文件調整 PDF 與 Word 的版面

處理 L1／L2：明確區分句中強調與區塊標籤，檢查短題組、導語與短回答的連頁，
並對 Word 的行距、段距、格線設定做有界線的比較。版面調整時固定實質文字，
完整文件比較允許經審閱的預期變化；歷史證據不覆寫，也不要求改善後必須與壞版面像素相同。

這三組工作不需要另養一套中文 Jinja、換成 runtime LLM，或重寫整個模板。
完成條件仍是使用者的三項要求；這次盤點不是放寬標準，也不是另一個升版理由。
