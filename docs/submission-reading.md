## 驗證與舊版保護

- `submission_reading_integration.py` 驗證實際 0.3.45 中英來源、ZIP 成員、資產內容、
  metadata、格式 UUID 與可重現的時間戳，必須完全符合已封存的完整來源演練。
- 新來源全部驗證後才可還原成精確 0.3.44；舊 0.3.44 結構 oracle 及更早的版本
  檢查繼續使用不可變的歷史來源。額外、遺漏或單一位元組變更均須失敗。
- 新版結構另外執行 3,312 組中英／輸出模式／版型／escaping 對照，不能以舊版
  還原檢查替代當前輸出檢查。
- 原生驗證必須把乾淨建置的 ZIP 原封不動送進本機 DSW，生成 HTML／PDF／DOCX，
  再檢查 Word 預覽、全文、標點、表格、座標及逐頁影像。演練套件不冒充新版套件。

目前的原生驗證腳本為 `scripts/check_submission_reading_native.py`；具體執行結果
由後續封存紀錄記載。LibreOffice 預覽不代表 Microsoft Word 跨版本排版驗收。

## 後續升級

新增客製問題先定義問卷路徑／回答完整性契約，再改英文共用來源及譯文。
每輪變更用短期工作分支與明確前後差異；中文鎖定完整英文 commit 和工具 commit。
