# 中文閱讀品質第二輪：實驗版 0.2.0

這輪回應「單看區塊沒有問題，整份文件卻很吃力」的審閱意見。
重點是資訊順序、段落組織與中文文體，不以頁數少或測試通過代替閱讀品質。
前一輪樣張仍保留於 `reviews/2026-09-11`，不覆寫。

已完成的本輪 [PDF／Word 對照樣張](../reviews/2026-09-11-readability/README.md)
與 [頁面審閱紀錄](../reviews/2026-09-11-readability/visual-review.md) 已封存。
30 份渲染、所選英中事實檢查及閱讀結構回歸通過，但整體驗收仍受 Markdown
表格與未完成的完整內容／Microsoft Word 審閱阻擋。

## 已改內容

- 首頁先呈現研究名稱、計畫概要與參與人員。聯絡人／作者不重複列同一組
  姓名和 email；角色、ORCID、所屬機構仍保留。模型版本改為首頁下方的
  次要資訊。PDF 和 Word 共用此內容；Word 不再自行加第二個標題。
- 保留 Science Europe 六節、十五題及題目原文；降低長問句的視覺重量，
  修正重複題目 ID，避免標題與小標題不斷打斷正文。
- 重用資料集的用途、來源與版本仍逐筆列出。只有所有已選參考資料集的
  保存副本／使用條件／格式處理皆已填且完全一致時，才集中說明共同規則。
  未知、不同或自訂條件不合併；非參考資料不被納入這個共同範圍。
- 第十五題改為「資源項目與用途／預算／經費來源」原生表格。零元仍是零元；
  只缺幣別時保留金額並準確提示幣別缺漏。Word 欄寬另設，不靠 PDF CSS。
- 培訓等引導句與後續回答以語意區塊處理；自由文字中的段落及清單不被
  自動摘要或改寫。中文改寫以完整句子為單位，不沿用英文片語的拼接語序。
- 移除會把讀者帶往空白答案的固定交叉引用，以及無回答的小標題／引言。
  經費未填不再變成「尚未申請」；無輸出不再以「沒有資料」代替。

## 三種狀態必須分清楚

1. `missing`：本輪已映射且檢查的欄位，沒有取得回答。
2. `missing-output`：文件中尚無相應說明；不能據此斷言使用者漏填。
3. `unmapped`：已知模板尚未接上問卷欄位，例如 Q5 的地點與備份頻率。

保留缺口，不藉由移除題目或補寫臆測讓文件看起來完整。`complete` 仍只表示
該欄位已取得值，不代表實質符合整個 Science Europe 要求。

## 版本、翻譯與可重建性

兩個 repo 都在短期 `feat/readability-pass` 工作分支；原實驗分支與原樣張不動。
英文自有版本與中文輸出版本本輪都為 **0.2.0**，但仍分開管理。精確英文來源見
`pipeline.yml`；官方基底仍是 1.30.1，沒有假稱本輪合併了新的 upstream release。

中文 canonical source 仍是 `translation/**/translation.md`。本輪審閱過的句對
保留於 `readability-phrases.json`；`scripts/apply_reviewed_phrases.py --apply`
僅是明確操作的開發遷移工具，不在建置或 runtime 自動翻譯。不匹配的新句子
不猜測、不填入舊翻譯。來源組織改變造成的檔案移動，與實際翻譯修改分開審閱。

英文共同規則、空答案判斷與頁面結構由英文 repo 維護；中文 repo 不增設一套
獨立 Jinja 業務邏輯。未來升級需按意義移植上游欄位／分支修正，再重跑英中
成品，而不是讓上游首頁覆蓋已重寫的首頁。

## 仍不得當作正式完成版

這是合成測試回答，不是讀取線上專案的內容。未全面驗收十五題所有條件；
第十二題等未覆蓋的子分支仍需後續稽核。尚未補齊問卷與 Science Europe 的
完整欄位對照，也未更改 KM、DSW worker 或線上模板。

使用者輸入的 Markdown 管線式表格仍是已知阻擋項。原生預算表能顯示，不能
據此宣稱 Markdown 表格已修好；Word 驗收會檢查真正的資料溯源表格標頭，
不接受用另一張預算表充數。Word 可編輯性與 LibreOffice 預覽不等於實際
Microsoft Word 跨平台驗收。後續仍需用代表性、去識別化的真實回答審閱。
