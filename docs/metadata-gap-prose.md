## 中英轉換與維護

原先把整句直接包兩個 span 的試作，被結構稽核擋下：翻譯後 span 遺失。
最後改由英文 Jinja 捕捉兩個帶標記的片語；翻譯樹新增兩個片語與一個含
具名 placeholder 的整句。中文可決定語序、分號與句號，不必維護 HTML 屬性。
翻譯工具仍鎖定 `25e339fbdfb1d20796471055790aad6a4226b6ed`。

原有 744 組 source/target 配對逐字保留，僅新增 3 組，共 747 組。
自動遷移對重複句「Each of those will use the following conventions:」無法
全部判定時，以原版同一段落的譯文還原，再以完整配對及完整 Q3 DOM 檢查核對。
不允許以「翻譯數量相同」取代內容一致性檢查。

中文 `pipeline.yml` 必須鎖定英文完整 commit；兩邊使用短期功能分支，
不是用一條永久中文程式分支與英文 Jinja 長期互相 merge。
上版翻譯、source hash、完整 Q3 fixture 及歷史失敗紀錄均保留。
