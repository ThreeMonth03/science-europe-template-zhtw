# Q5 Word 固定說明合段：0.3.35 實驗

此輪只改英文共用 Word Lua：將已通過短篇資格判定的「工作區政策」和
「執行限制引言」合成一段，以真正的換行分隔。兩句原文、限制清單和最後
一項不連住 Q6 的規則保留。不是在產出後用 UNO 重排或修改 DOCX 補救。

HTML／PDF 的 Jinja 和 CSS、問卷欄位映射、744 個翻譯檔、字型、字級、
段落樣式及 reference DOCX 都不變。中文仍由既有英文→中文流程產生。
長回答、複雜標記、自由填答及帶有封存細節的分支仍使用原流程。

## 驗證方式

英文新探針用固定 Pandoc 檢查 31 組正反例，包含中英、長度邊界、既有多項
固定政策合段、原始標點、錯誤提示與複雜內容。可逆的來源契約先把本輪的
唯一合段改動還原成 0.3.34，再跑舊版 hash／樣式門檻；另用新的 AST 和
DOCX 檢查只允許原有 runs 加一個普通換行，不能忽略整個 Q5 的差異。

`check_q5_word_join_outputs.py` 比較同一組十案例的前後原生產物：
空白、否定、各種後設資料漏填／完整、儲存共享及長預算，英中各一份。
它要求十五題 HTML 不變、PDF 正文與座標不變，Word 除指定合段外的 XML
不變；保留完整回答、標點、編號、連結及樣式。合格 Q5 必須整組同頁，
不合格者整份 Word 正文座標不變；頁數不得增加。

原生 PDF／DOCX、重新開啟的 LibreOffice 預覽及頁面視覺檢查尚須各自完成，
不能拿結構探針替代。0.3.34 的失敗和四頁縮減反例保持原樣，不覆寫成通過。
這是短期 `fix/word-context-layout` 分支的實驗，不新增永久中英文產品分支。
