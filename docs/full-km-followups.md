# 0.3.46：完整 KM 的三項追問修補整合

本輪把[先前已驗證的原型](full-km-followup-prototype-review.md)接回英文共用來源，
中文仍經既有展開／翻譯／建置流程生成，沒有手改中文 Jinja，也沒有使用 LLM 改寫回答。

範圍是三項曾漏出的回答：Q3 檔案命名規則（SE-2a）、Q10 計畫建立之參考資料的
發布時程（SE-5a）、Q11 維護方式（SE-5b）。原有儲存系統命名答案仍獨立保留。
依完整 KM 的題目關係及實際選項判定是否啟用；停用分支、被篩掉的題目不輸出舊答案。
啟用但漏填者在內部檢核版提示，提交預覽不印提示、不憑空補寫事實。

只有六個新增翻譯項目，原有 767 個全部保留，合計 773 個。新增引導標籤使用冒號，
缺漏提示使用完整句號；使用者原文的 Markdown、大小寫、標點不更動。Q10 識別碼
採局部 CSS 修補，避免類型與值被錯當標題拆開；字型和 Word 轉換步驟不變。

## 版本與回歸檢查

兩個 repo 同用短期 `fix/full-km-followups` 分支與 0.3.46 版號，中文以 `pipeline.yml`
鎖定英文完整 commit。原型分支及舊證據保留；檢核／提交是同一份來源的輸出格式，
不是兩條長期分支。尚未合併、發布或部署，後續仍須按正式驗收決定是否升級。

`full_km_followups_integration.py` 先驗證實際新版套件所有來源／資產、六項翻譯差異、
格式與轉換步驟、版本 UUID 與時間戳，再執行中英各 240 組新分支檢查。
原型套件 fixture 來自已封存、雜湊固定的 ZIP，不從本輪待測輸出產生答案。

舊版逐位元組測試仍保留，透過嚴格驗證後的歷史來源視圖執行；這些視圖只供測試，
不會拿來發布，也不冒充實際新版渲染。新版原生 PDF／Word 對照另記錄，不能把
歷史 3,312 組比較說成新的完整 KM 覆蓋。

本輪不代表完整 Science Europe 題目覆蓋、全域提交提示開關、DSW 線上安裝或
Microsoft Word 全篇驗收。私有專案回答與產物留在 repo 外，不提交到 GitHub。

## 下一輪優先處理

1. 整篇閱讀：短段落密度、引導句與回答銜接、中英文一致的敘述語氣。只整理模板
   固定敘述，不自動改寫使用者原文。
2. 提交前完整性：缺漏留在內部檢核，不混入提交文件；另決定空題標題的呈現規則，
   不以刪掉要求或虛構答案假裝符合 Science Europe。
3. 升級測試：未來 KM 升版必須拿新版編譯後的題目關係重新驗證映射，不只重跑舊
   fixture；upstream 模板更新也須在短期 upgrade 分支上審閱差異與中英輸出。
